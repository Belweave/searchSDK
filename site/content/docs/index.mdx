## Install

`searchsdk` is not on npm yet. Pack it from the repository and install the tarball:

```sh
cd searchSDK/sdk/typescript
npm ci
npm pack --ignore-scripts=false
cd your-app
npm install ../searchSDK/sdk/typescript/searchsdk-0.0.0.tgz
```

It has no runtime dependencies and needs a standard `fetch`. Tested on Node 24.

## Add a key

Each provider reads its documented variable, such as `EXA_API_KEY`. Keys stay on your server and are never logged.

```sh
export EXA_API_KEY="your-key"
```

## Search

```ts
import { search } from "searchsdk";

const { results, cost } = await search("vector database indexing", { provider: "exa", maxResults: 5 });
for (const r of results) console.log(r.title, r.url);
console.log(cost.usd, cost.source);
```

## Fall back

A client can try other providers, in order, when one is unavailable, rate limited, out of quota or cannot honour an option. Fallback and retries are off unless you set them.

```ts
import { createClient } from "searchsdk";

const client = createClient({ provider: "exa", fallback: ["tavily"], maxRetries: 1 });
const res = await client.search("vector database indexing");
console.log(res.provider, res.attempts.length);
```
