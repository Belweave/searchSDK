## CostBound

Returned by `costBound(spec, kind, input)`. `listPrice(spec, kind, { count })` returns a `Cost`.

| Name | Type | Meaning |
| --- | --- | --- |
| `usd` | `number \| null` | The most one request can cost at the highest documented rate, or `null` when it cannot be bounded. |
| `unknownBecause?` | `"option" \| "count" \| "price"` | Why `usd` is null: `option` (a cost option has no price), `count` (the billed count is unbounded) or `price` (not public). |
| `requiresOverageOff?` | `true` | Present when the bound holds only while paid use past a free allowance stays off on the account. |
