Usage and billing API
Usage and billing API


These endpoints require a signed-in user’s access token. Organization owners and admins can manage billing and paid storage. Other workspace members with read access can view the storage plan and allowance. Payment links and available credit balances are visible only to billing administrators.


See 
authentication
 for request headers and response formats, and 
error recovery
 for help with failed requests.


Use Billing in the Console


Open 
Billing
 in the 
Console
 
 to review credits, set up auto-topup, buy credits, and manage invoices. To perform these actions through the API, authenticate with the user’s access token as described in 
authentication
.


The wallet response shows your total balance, credits reserved for work in progress, available credits, and storage allowance. Follow the returned hosted checkout URL to confirm a purchase, then check status afterward. A browser redirect alone is not confirmation of payment.

Idempotency-Key

Storage changes


Read workspace storage, request a quote for the desired capacity, and confirm the quote while it is current. The quote shows the charge, credits applied, and renewal date. Available credits must cover the full charge. Paid capacity costs $0.33 per selected decimal GB per month, with a separate renewal period for each workspace.


Use 
selected_gb: 0
 for the free allowance, or a whole number within the returned policy bounds for paid capacity, currently 5–100 GB. Used plus reserved bytes must fit the selection.




GET 
/v1/workspaces/{workspace_id}/storage
 and check 
can_manage
, used/reserved bytes, and policy bounds.


POST 
/v1/workspaces/{workspace_id}/storage/quote
 with 
{"selected_gb":10}
.


Present the charge, credits applied, effective date, and expiry for review.


POST 
/v1/workspaces/{workspace_id}/storage
 with 
{"quote_id":"RETURNED_QUOTE_UUID"}
 and a new idempotency key. Use the same signed-in account that requested the quote.


Read storage status again and confirm the capacity is active.




Quotes last up to five minutes and may expire sooner at the billing boundary. If the available balance is insufficient, add credits and request a fresh quote. For an outstanding invoice from an earlier billing arrangement, read 
payment_recovery_status
 for the next step and 
next_payment_attempt
 for a scheduled retry. These fields can be null when no recovery state or retry time is available. Payment methods can be managed through the payment portal.

Search spending caps


For prepaid-credit accounts, caps apply to reserved plus settled search spending in the current UTC calendar month. Organization, workspace, and key caps can each block a request with 
search_budget_exceeded
. A larger credit balance does not raise these caps.


An organization has no cap until you set one, and its cap reads as 
9223372036854.775807
. Workspace and key caps exist only after you set them. There is no request to remove a cap. To lift one, set it to the largest accepted value, 
999999999999.999999
. A cap of 
0.000000
 blocks every charged search in that scope.
